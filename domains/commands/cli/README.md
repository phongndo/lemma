# commands.cli

The palette's commands for the `lemma` command (`CliCommands` in [`@lemma/cli`](../../cli/README.md)): `commands` lists what plugins add to `Commands` (`@lemma/commands`), and `commands run <id>` runs one in the client's directory (or `--cwd`), its questions carrying the run's origin, which the client answers. Requires nothing: it reaches them through their channels. No config.
