# threads

A session as the web app shows it: the thread page, its views (the transcript, the trajectory), and the composer. Its contract is [`@lemma/threads`](contract/src/threads.ts), with the projections the views share.

| Plugin                                        | Halves | What it does                                                                                                                                                                                                                                                                    |
| --------------------------------------------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`threads.client`](client/)                   | web    | Threads and the active one's log: provides `Threads`                                                                                                                                                                                                                            |
| [`threads.view`](view/)                       | web    | The page for one thread, and for a new one (its prompt in the middle, over `ThreadStart`): the chat, the thread card (`ThreadCard`, with its own cost row) over its top right, and beside it the thread's inspection pane, whose tabs are its other views (⌘I): provides `Pane` |
| [`threads.transcript`](transcript/)           | web    | The session as a conversation                                                                                                                                                                                                                                                   |
| [`threads.trajectory`](trajectory/)           | web    | Every request, response, and tool call, as a network panel shows them, with each one's pipeline: who shaped it, from the log                                                                                                                                                    |
| [`threads.composer`](composer/)               | web    | A prompt being written, with its completions, controls, and queue                                                                                                                                                                                                               |
| [`threads.prompt-commands`](prompt-commands/) | web    | The `/` menu: `PromptCommands`, their subcommands, and their arguments, completed and hinted in turn; adds `/new`, `/rename`, `/copy`                                                                                                                                           |
| [`threads.browser`](browser/)                 | web    | A browser as a view of the thread, in its pane: Chromium with DevTools in the desktop app, a frame elsewhere                                                                                                                                                                    |

## Extending it

What the contract offers in each of the [five shapes](../../docs/plugins.md#the-five-shapes):

| Shape     | What the contract offers                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Add       | `Views` (a view of a thread: the first fills the page, the others open as tabs in the inspection pane, by letter, with a name per tab), `ToolViews` (how a tool's calls show: their line, opened, and what they show the reader outside the fold, such as a page drawn), `ThreadHeader`, `ThreadActions`, `ComposerControls`, `ComposerCompletions`, `PromptCommands` (`/new`, `/mcp tool github create_issue hidden`), `ComposerActions`, `ComposerNotices`, `ComposerTakeovers` (the text box and send button, for a while), `TurnOptionSources` (a plugin's choice sent with each prompt, as the agent's `TurnOptions.plugins`), `ComposerFooter`, `ThreadStart` (under a new thread's prompt, until it is sent: what it starts with, its mode and project), `ThreadCard` (rows of an open thread's facts, in the card its header's switch keeps open over the chat: its mode, where it works, its context, its cost), `PromptActions` (buttons under a prompt in the transcript: Edit from here, copy, link), `ErrorActions` (buttons under a failed model request: what would fix it, such as signing in to its provider again), `TrajectoryTabs`, `TrajectoryActions`, `ThreadWaits` (threads waiting on the person: `Needs input`), `ThreadHolds` (what a plugin keeps for a blank thread, which keeps it) |
| Intercept | Parts that take over how a piece draws: `ChatToolPart`, `ChatUserPart`, `ChatThinkingPart`, `ChatWorkPart`, `ChatWorkGroupPart`, `ChatWorkingPart`, `ChatTurnFooterPart`, `ComposerQueuedPart`, `ComposerSuggestionPart`, `SidebarRowPart`; `ComposerRegion`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Observe   | `Threads`' signals: the active thread, its branch, whether it is blank, what runs, unsent prompts (`drafts`); `Pane`'s tabs, every thread's                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Call      | `Threads`: open, create (a new thread, empty), send (in the background too), steer, queue, rename; `Pane`: open a view's tab                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Serve     | `Threads`: a plugin providing it replaces `threads.client`; `Pane`, `threads.view`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
