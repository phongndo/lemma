# tools

What the model can call, and how calls run. Its contract is [`@lemma/tools`](contract/src/tools.ts), with helpers for tools that bound their output, touch files or inline images (`/files`), show changes to text (`/diff`), read and apply Codex's patches (`/patch`), draw pages in the chat or check them (`/html`), and test themselves (`/testing`).

The file tools reach any path the host's user can, not only the project's:
confining them is a policy, and `Guards` is where a plugin sets one
([approvals](../../examples/approvals/README.md)). Writes replace a file whole
or not at all, keeping its mode and writing through symlinks (`replaceFile`);
a file another user owns, or in a directory the user cannot add to, is written
in place. Output too long for a result goes to a temp file only the user can
read, which the host keeps while it is written and then among its newest 100
while it runs (`outputFile`).

| Plugin                                     | Halves     | What it does                                                                                                                                                   |
| ------------------------------------------ | ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`tools.registry`](registry/README.md)     | host       | Lists and runs the tools: provides `ToolRunner`, checking each call with the guards                                                                            |
| [`tools.read`](read/README.md)             | host + web | The `read` tool, and how its calls show                                                                                                                        |
| [`tools.write`](write/README.md)           | host + web | The `write` tool, and how its calls show                                                                                                                       |
| [`tools.edit`](edit/README.md)             | host + web | The `edit` tool, and how its calls show                                                                                                                        |
| [`tools.patch`](patch/README.md)           | host + web | The `apply_patch` tool: Codex's patches, and how its calls show                                                                                                |
| [`tools.bash`](bash/README.md)             | host + web | The `bash` tool, and how its calls show                                                                                                                        |
| [`tools.codemode`](codemode/README.md)     | host + web | The `codemode` tool: JavaScript in a sandbox that calls the other tools and classifier and image models, resumed after a restart; its calls live in the chat   |
| [`tools.search-fff`](search-fff/README.md) | host + web | The `grep` and `find` tools, searching with fff, and how their calls show                                                                                      |
| [`tools.ask`](ask/README.md)               | host + web | The `ask_user` tool: questions for the user, answered above the composer                                                                                       |
| [`tools.html`](html/README.md)             | host + web | The `html_render` tool: a page the model made, shown to the person in the chat outside the fold                                                                |

A plugin replacing `tools.registry` runs `toolsConformance` from `@lemma/tools/testing`: the tests `tools.registry` passes, against the contract alone.

## Extending it

What the contract offers in each of the [five shapes](../../docs/plugins.md#the-five-shapes):

| Shape     | What the contract offers                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Add       | `Tools`: a tool (one that runs others `nests`; one only such a tool calls is `nested`, so the model is not sent it while one is offered, `declaredTools`), with what a script's call of it resolves to (`output`, the result's `structured`), the namespace it belongs to (`namespace`), whether its calls show the person something (`display`), and whether running it again would not give its results back (`irreplaceable`, so they are not shortened); `ToolNamespaces`: a group of tools scripts reach together, with instructions they read on demand; `Guards`: a check every call of a tool (or `*`) passes before it runs. A tool's web half adds how its calls show to the threads domain's `ToolViews` |
| Intercept | `ToolExecuteHook`: around every call (rewrite it, time it, answer it)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Observe   | `ToolExecuted`: each result, with its duration; `ToolOutput`: a running tool's output                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Call      | `ToolRunner`: list and run the tools                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Serve     | `ToolRunner`: a plugin providing it replaces `tools.registry`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
