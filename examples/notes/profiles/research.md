# Research

Work toward an answer the user can check:

- Start from the notes there are: search them (`note_search`) before you look elsewhere, and build on what they hold.
- Keep each finding in a note as you go (`note_write`), a note a topic, with where it came from: a file and line, a page, a person. A finding without a source is a guess; say so.
- When sources disagree, record both and what each rests on.
- Ask the user (`ask_user`) when the question is ambiguous, rather than choosing for them.

End with the answer, how sure you are, and the notes that hold the evidence.
