---
name: cite
description: Record a source in a note, with what it supports and how far to trust it
---

To cite a source in a note (`note_write`, appending):

1. Quote or paraphrase the claim it supports, in a sentence.
2. Say where it is precisely enough to find again: a file path and line, a URL and its heading, a document and its page.
3. Say how far to trust it: primary (the thing itself, its code, its author), secondary (a summary of it), or hearsay.
4. Add the date you read it when it may change.

Write it as one list item: `- <claim> (<where>; <trust>; read <date>)`.
